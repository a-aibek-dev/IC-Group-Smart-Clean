# IC Group: Smart Clean OS

Смарт-система управления уборкой для хакатона: мобильное приложение клинера + дашборд менеджера с визуальным конструктором маршрута.

## Запуск (всё — в Docker, npm внутри контейнера)

```bash
docker compose up -d
```

Откройте **http://localhost:5173**

### Hot-reload без перезапусков

Весь проект примонтирован в контейнер (`.:/app`), а `node_modules` живёт в отдельном
volume контейнера — хост остаётся чистым:

- **любое** изменение (`src/`, `index.html`, `tailwind.config.js`, `public/`, конфиги) —
  подхватывается мгновенно через Vite HMR, **docker пересобирать/перезапускать не нужно**
- `npm install` выполняется только при сборке образа или вручную:
  `docker compose exec app npm install <пакет>`
- если изменили зависимости в `package.json` — достаточно
  `docker compose exec app npm install` (volume обновится без пересборки образа)

## Phone-first (для жюри на телефонах)

Приложение оптимизировано под смартфоны:

- **На телефоне** интерфейс заполняет весь экран (без рамок), корректная высота `100dvh` (без прыжков при скрытии адресной строки)
- **PWA**: в Chrome/Safari можно «Добавить на главный экран» (manifest + иконка)
- **Кнопка «Отправить ссылку жюри»** на стартовом экране — нативный share-лист (QR / мессенджер) или копирование ссылки
- **Drag&drop зон в дашборде** работает на тач-экранах (TouchSensor)
- Режим демо на маленьких экранах складывается вертикально

Чтобы на десктопе телефон-вид клинера не растягивался на весь экран, он показывается в рамке смартфона по центру.

- **«Я — Клинер»** — мобильное приложение (жёсткий маршрут, цветовое кодирование зон, pH-регламенты, чек-листы со скрытыми деталями, фото-антифрод). На десктопе показывается в рамке телефона.
- **«Я — Менеджер»** — дашборд (статистика, Drag&Drop конструктор маршрута, live-мониторинг)
- **«Режим демо (питч)»** — телефон клинера + проектор менеджера в одном окне (iframe)

## Live-синхронизация между окнами

Маршрут синхронизируется между всеми открытыми окнами/вкладками через `BroadcastChannel`:

- менеджер **перетащил зону** в конструкторе → у клинера маршрут меняется сразу (+ тост «Супервайзер обновил маршрут»)
- клинер **отметил задачу / завершил зону** → на дашборде менеджера статусы и индекс чистоты обновляются в реальном времени

Попробуйте: откройте `http://localhost:5173` в двух вкладках (одна — клинер, вторая — менеджер) или используйте режим демо.

Пересборка после изменения зависимостей:

```bash
docker compose build
```

## Структура

```
src/
  components/   — экраны: Login, CleanerRoute, CleanerZone, ManagerDashboard, DemoMode
  data/mock.ts  — моки: профиль, зоны, умные шаблоны (цвет + pH + чек-лист)
  store.tsx     — глобальное состояние (маршрут, задачи, фото-верификация)
  types.ts      — типы
```

## Ключевые фичи из docs/

- **Анти-хаос**: зоны строго по шагам, следующие заблокированы до завершения текущей
- **Цветовое кодирование + pH Scale**: синий (общие, pH 7), красный (санузлы, pH 3), зелёный (кафетерии, pH 8), жёлтый (грязные зоны, pH 4)
- **Эффект ореола**: скрытые детали (ручки, выключатели, кнопки смыва) выделены отдельным блоком
- **Фото-антифрод**: проверка GPS + EXIF перед завершением зоны
- **Умные шаблоны**: добавление зоны в маршрут автоматически подтягивает цвет, регламент и чек-лист
